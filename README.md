📊 My Power BI Project Blinkit Sales Analysis Dashboard | End-to-End Data Analytics Project
I am excited to share my latest Data Analytics project  Blinkit Sales Analysis Dashboard created using Microsoft Power BI.
The main objective of this project was to analyze Blinkit’s sales performance, understand outlet-level performance, and identify meaningful business insights through interactive data visualization.
📌 Project
In this project, I developed an interactive dashboard to analyze sales data across different outlet locations, outlet sizes, item types, fat content, and establishment years.
The dashboard helps users understand key business metrics and explore sales performance using interactive filters and visualizations

📊 Key Performance Indicators (KPIs)
1. Total Sales: $1M = Overall revenue generated.
2. Average Sales: $141 = Average sales value.
3. Number of Items: 8,523 = Total items sold.
4. Average Rating: 3.9 = Average customer rating.

📈 Dashboard Features & Analysis
 Sales Performance Analysis
1. Analyzed overall sales performance.
> Compared total sales and average sales.
> Evaluated business performance using KPI cards.
2. Outlet Establishment Analysis
>  Analyzed sales based on outlet establishment year.
>  Compared outlet performance across different years.
>  Identified sales trends over time.
3. Outlet Size Analysis
>  Compared sales across Small, Medium, and High outlet sizes.
>  Analyzed the contribution of different outlet sizes.
 4. Outlet Location Analysis
>  Compared sales across different outlet tiers.
>  Analyzed the performance of Tier 1, Tier 2, and Tier 3 locations.
 5. Fat Content Analysis
>  Compared Low Fat and Regular products.
>  Analyzed their contribution to total sales.
6. Item Type Analysis
>  Analyzed sales across different product categories.
> Identified categories contributing to overall sales.
7. Interactive Filter Panel
> Outlet Location Type
> Outlet Size
> Item Type
These filters allow users to explore the dashboard dynamically and view specific business insights.
